# Desktop Screenshot

把当前桌面（含所有显示器）截成一张 PNG，保存到固定的截图片目录，并返回图片的完整路径。常用于远程查看电脑当前状态，然后由调用方读取图片。

## 使用步骤

1. 用脚本捕获屏幕：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "<此技能目录>\scripts\take_screenshot.ps1"
   ```
2. 脚本会打印出生成的图片完整路径（形如 `desktop_20260830_123456.png`），读取该路径。
3. 若调用方需要把图片发给用户，从该路径读取图片。

## 行为细节

- `take_screenshot.ps1` 通过 C# 辅助类 `ScreenCaptureHelper` 用 `EnumDisplayMonitors` + `GetMonitorInfo` 枚举所有物理显示器，求它们外接矩形的并集，再用 `CopyFromScreen` 一次捕获整块区域。无论几块屏、如何排列（含副屏在主屏左侧的负坐标布局）都能截全。

  - 单显示器：就是这一块屏；
  - 多显示器：拼成一张覆盖全部屏幕的图。
  - 脚本会输出 "Screens: ..." 一行的每屏坐标信息，便于排查。
  - DPI 感知通过 `SetProcessDPIAware()` 声明，保证坐标是物理像素，避免高缩放（如 175%）下截图偏移。

- 默认保存目录：技能目录下的 `screenshots/`。可通过 `-OutputDir` 参数覆盖（幂等，会自动创建子目录）。
- 文件名用时间戳命名，天然不会重名，每次调用生成一张新图。
- 输出图像为 PNG 格式。

## 注意事项

- 截图脚本是 Windows PowerShell / .NET 实现，零第三方依赖。
- 若用户后续增加"发送图片"能力，这一步只负责产图。图片生成后交给调用方处理发送。
- 图片保存成功后，务必把完整路径作为结果返回，不要只回一个"已保存"。
